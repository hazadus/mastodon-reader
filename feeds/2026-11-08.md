💬 LMAO, celeste code that uses a switch statement to check that the player state isn't of values 12, 13, 14, or 15 gets optimized by the compiler to instead be:

if((uint)(state - 12) > 3u)

uint is unsigned integer. negative numbers when cast to uint become values between 2147483648 and 4294967295.

therefore, values such as 11 after the subtraction become negative and then are cast to uint to become really big positive numbers, which are thus over 3. values 12 to 15 are less than or equal to 3 after the subtraction (0 to 3). values over 15 after the subtraction are still higher than 3.

💬 Python Tip #311 (of 365):

Make directories with parents and exist_ok.

Like this:
pathlib.Path("reports/2026").mkdir(parents=True, exist_ok=True)

Without "parents=True", the mkdir method raises an exception when parent directories are missing:

>>> reports = Path("reports/2026")
>>> reports.mkdir()
FileNotFoundError: [Errno 2] No such file or directory: 'reports/2026'

Passing "parents=True" will create missing parent directories.

💬 Today I'm writing about the Go's Profile-Guided Optimization (PGO), where you hand the compiler a profile of a real run and it optimizes the code that is actually hot, without touching your source.

From the profile, the compiler does three things: guesses the concrete type behind interface calls, inlines much bigger functions at hot calls, and aligns hot loops to cache lines. We will see each of those in detail.

The article will be out tomorrow!
