💬 Django 6.1 added model field fetch modes:

• FETCH_ONE: the old default, 1+N queries
• FETCH_PEERS: loads the missing field for every instance from the same queryset, so 2 queries, and the mode propagates down the relation tree
• FETCH_RAISE: raises FieldFetchBlocked instead of quietly querying

The boundary: FK, OneToOne, deferred fields and generic relations. Not related-manager queries (reverse FK, M2M).
