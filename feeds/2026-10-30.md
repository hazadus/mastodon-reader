💬 ual v0.7.6 is out

ual is a stack-based, coordination-first language: one interpreter, compilers to Go and Rust.

New: cual/SDCC. This release adds a simple experimental C backend for the Z80 (ZX Spectrum, CP/M) via SDCC. A subset for now; 13 of 92 examples match the interpreter on an emulated Z80. For the examples that need host system support, concurrent programming and floating point features are being developed in parallel to ual, and will be integrated in forthcoming releases. (the first of which is [#zenpoint](https://oldbytes.space/tags/zenpoint))

The 92 existing correctness examples now give byte-identical output across iual, Go, Rust, WASI, and WASM on the browser.

Additional work was done –and is still ongoing– to further enhance the tual/TinyGo harness targeting embedded architectures, as upstream TinyGo closed a number of issues in the intervening time since ual v0.7.5 was released 10 months ago. A follow-up release to complete tual support is coming soon.
