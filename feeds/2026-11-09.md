💬 s[start:end:cap] , ça vous dit quelque chose?
👇

§10.2 dans ≡Go Avancé de Thierry Fournier
[#golang](https://hachyderm.io/tags/golang)

![Syntaxe de slicing étendue

Go propose une syntaxe à trois indices `s[start:end:cap]` pour contrôler précisément la capacité résultante. Cette forme limite la capacité du nouveau slice, empêchant l'accès aux éléments au-delà de la position `cap` dans le backing array :

    data := make([]int, 8)
    // Remplissage : [0,1,2,3,4,5,6,7]
    for i := range data {
        data[i] = i
    }

    normal := data[2:5]      // cap = 6 (jusqu'à la fin)
    limité := data[2:5:6]    // cap = 4 (limité explicitement)

    // normal peut s'étendre jusqu'à l'index 7
    fmt.Println(cap(normal))  // 6

    // limité ne peut s'étendre que jusqu'à l'index 5
    fmt.Println(cap(limité))  // 4

Cette limitation de capacité protège contre les accès accidentels aux données situées au-delà de la zone prévue, créant une forme d'encapsulation au niveau du slice.](https://cdn.fosstodon.org/cache/media_attachments/files/117/586/345/608/277/095/original/7870af07606432e7.png)
