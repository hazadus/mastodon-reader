💬 ZenZX v0.6.11 is out

— a preview release on the ramp-up to v1.0.

ZenZX is a ZX Spectrum emulator in Go (48K/128K/+2/+3, now TS2068 too).

What's new:

New menu system: Light, Dark, and Spectrum themes, selectable fontsGUI toolkit reused from zenimate, including file dialogsTS2068 support, with hi-colour modeTape loading improved: new -tapemode=turbo, more precise .tap/.tzx decoding via zentoolsULA memory contention implementedJoystick (Kempston, Sinclair) and mouse (Kempston, AMX) supportBuilds for Windows, Mac, FreeBSD, and Linux available. This is an interim release, no guarantees whatsoever, BUGS ARE EXPECTED and feedback is very, very, welcome! 

More to come before v1.0.
