💬 🐧🎓 Les presento LearnHouse: la plataforma LMS open source "next-gen" que le hace competencia a Chamilo y Moodle, pero con un enfoque moderno y IA integrada desde el diseño.

Licencia AGPL-3.0, stack FastAPI + Next.js, y un editor tipo Notion que enamora. Les cuento por qué es otra cosa 🧵

🚀 Lo que lo distingue:

✅ Editor block-based (tipo Notion) para crear cursos sin pelear con HTML
✅ Ejecución de código REAL en 30+ lenguajes con auto-calificación (¡ideal para cursos de programación!)
✅ Pizarras colaborativas en tiempo real (tipo Miro)
✅ Playgrounds con IA: genera simulaciones, diagramas y ejercicios interactivos
✅ Certificados automáticos al completar cursos
✅ SEO integrado + custom branding

🛠️ Stack técnico moderno:

Backend: FastAPI + Python + SQLModel + PostgreSQL + Redis
Frontend: Next.js + React + TailwindCSS + Tiptap (editor)
Tiempo real: Hocuspocus + Yjs + WebSocket
IA: Integración nativa para generación de contenido

Requiere ~2GB RAM (PostgreSQL + Redis + 3 servicios Node). Más pesado que Chamilo (~512MB), pero mucho más potente. ⚖️

📦 Instalación con CLI oficial:

# Self-host (producción)
npx learnhouse@latest setup
npx learnhouse start

# Desarrollo local
git clone [https://github.com/learnhouse/learnhouse.git](https://github.com/learnhouse/learnhouse.git)
cd learnhouse
npx learnhouse dev

El wizard te guía por dominio, DB, admin y features. Docker hace el trabajo sucio. 🐳

🌉 Nexo con nuestra saga:

Si Chamilo es el LMS "roca sólida y liviano" (2 vCPU + 2GB RAM), LearnHouse es el LMS "next-gen con IA" (más pesado, más potente).

¿Cuál elegir?
→ Chamilo: escuela rural, hardware modesto, foco en contenido tradicional
→ LearnHouse: cursos de programación, colaboración en tiempo real, IA integrada
