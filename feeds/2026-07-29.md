💬 TIL: Les deux snippets ci-dessous ne sont pas équivalents.

```
from django.test.client import Client
client = Client()
client.session["meuh"] = "truc"
client.session.save()
```

vs.

```
from django.test.client import Client
client = Client()
session = client.session
session["meuh"] = "truc"
session.save()
```

Pourquoi ?

> because a new SessionStore is created every time this property is accessed
