💬 4. The JIT pays off in CPU-bound loops with predictable types (numerics, parsers, encoders).

I/O-bound web handlers gain little. NumPy and Cython gain almost nothing, as that work runs in C.

Rule of thumb: on for CPU-bound batch jobs, off for production web services for now.
