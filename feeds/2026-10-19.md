💬 quicktipp #123: Modern MS Windows supports true, Unix-style bind mounts.

The wbind CLI tools makes it easy to create, remove and list them. This lets you make a file or directory from another local or UNC path virtually appear at a different local path.

[https://github.com/christian-korneck/wbind](https://github.com/christian-korneck/wbind)

# for this demo, let's pick a destination file path and make sure it does not exist yet:
PS> dir c:\calcy.exe
File Not Found

# bind-mount the calc.exe file from the Windows dir to the destination c:\calcy.exe
PS> wbind mount c:\windows\system32\calc.exe c:\calcy.exe

# now the file exists virtually (as an in-memory / ephemeral bind mount - it only lasts until the next reboot):
PS> dir c:\calcy.exe
calcy.exe

# we can also bind-mount a directory
PS> wbind mount c:\windows c:\demo

PS> dir c:\demo
...
System32
SystemApps

# we can list all bind mounts currently present on the system
PS> wbind ls
TARGET              SOURCE                        OPTIONS
C:\calcy.exe        C:\Windows\System32\calc.exe  rw
C:\demo             C:\Windows                    rw
