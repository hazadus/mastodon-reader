💬 Python Tip #266 (of 365):

Reread a file with seek(0).

Try to .read() a file twice, and you'll get nothing the second time:

>>> f = open("my_file.txt")
>>> f‍.read()
'This is my file 👋\nThis is line 2\n'
>>> f‍.read()
''

Python keeps track of your position within a file as you read.

When you're at the end, another read returns an empty string.

The seek method changes that position.

💬 New on the blog: Jev vs Laya on Prompt forward 🧭

My old model router (ai-dispatch) had an LLM read a long prompt and pick an agent, and each agent had a fixed model. It knew nothing about cost or confidence, and it never learned.

So I rebuilt it around a new kind of model: "System One" decision models. They answer typed questions with calibrated probabilities instead of writing text.
➡️ An OpenAI-compatible gateway in Go: send model: "auto"
➡️ Jev (TypeSafe, called through OpenRouter) or Laya (Convai Innovations, running locally) answers 4 questions: topic, complexity, risk, private data
➡️ Plain arithmetic over a YAML file picks the cheapest model that clears the quality floor. There's no LLM in the scoring.
➡️ The model stays fixed for the whole conversation (keeps the prompt cache), falls back on 429/5xx, and runs a local privacy check first

I benchmarked 80 prompts, Jev against 3 Laya checkpoints:
📊 Jev: 89% topic accuracy, 70% of routes identical to the gold route, and 42% cheaper than always-Opus
📊 Laya out of the box is unsure, and an unsure router over-provisions: its routes cost more than Jev's even though each decision is free
Also in the post: a reasoning-token surprise (1,796 tokens to say "hi"), how a prompt injection got routed to the cheapest model, and the lessons learned.

Built in one Claude Code session, and everything is public:
