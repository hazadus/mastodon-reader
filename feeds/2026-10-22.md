If you are using Docker layer caching, that can cache the base Linux distribution's packages.

💬 potatoq has a dashboard now 🥔

The first question after launch was "where's the Flower equivalent?", so here it is:

• Live workers and the tasks they're running
• Queue sizes and periodic tasks
• Dead letters with the traceback, and a Retry button

It reads the broker directly: no events to turn on, nothing lost on restart. No extra dependencies either: `potatoq dashboard`, or mount it in Django, FastAPI or Flask.
